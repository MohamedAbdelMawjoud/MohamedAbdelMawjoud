### 🔧 Technologies

`YOLO11m` `PyTorch` `Optuna` `ONNX` `TFLite` `FastAPI` `Docker` `Azure` `GitHub Actions` `Prometheus` `Grafana`

* 🎯 **mAP@50:** 94.2%
* 📊 **mAP@50:95:** 76.8%
* ⚡ **~250 FPS** using GPU ONNX FP16
* ⏱️ ~4 ms/image inference
* 📦 Model size: ~38.8 MB
* 🔍 Hyperparameter optimization using Optuna
* 🚀 Deployment-ready inference pipeline

### 🎯 Detection Classes

* Vehicle → Car / Van / Truck
* Pedestrian → Pedestrian / Person Sitting
* Cyclist
